# Urban Company Mobile UI Template

An editable local prototype reconstructed from the supplied Android screenshots.

## Open it

Open `dist/index.html` in Chrome, Edge, Firefox, or Safari. No installation or internet connection is required.

## Included

- 360 × 800 Android phone canvas without system status icons
- Authentication, OTP, location, home, search and category screens
- Beauty, cleaning, appliance-repair and home-service catalog screens
- Cart, saved-address, arrival, scheduling, payment and confirmation flow
- Profile, bookings, devices, wallet, gift-card, settings and support screens
- Automatic and draggable advertisement carousel with pagination dots
- Reusable CSS components and data-driven JavaScript screen generation
- Personal information replaced with editable placeholder content

## Edit it

- `dist/index.html` — prototype shell
- `dist/styles.css` — design tokens and reusable components
- `dist/app.js` — screen content, routes and interactions
- `dist/assets/` — imagery extracted from the supplied screenshots

This is an independent UI recreation for prototyping and study. Urban Company trademarks and source imagery remain the property of their respective owners.
